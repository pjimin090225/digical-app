3. (권장) 미리 만들기: 앱 주소 끝에 ?dev=1 을 붙여 열고 → 메뉴 → 전시실 → 작품을 하나씩 눌러 AI 분석과 음악이 끝날 때까지 기다림
   → 전시실로 돌아와 'cache-번호.json 내려받기' → 받은 파일을 이 폴더에 올리기
   그러면 관람객은 기다림 없이 바로 보고, AI 사용료도 들지 않아요. (그림을 바꾸면 다시 만들어야 해요)
4. 포스터 QR: 사이트의 qr.html을 열면 맨 위에 '전시실 QR'이 있어요. PNG로 받아 포스터에 넣으세요.
